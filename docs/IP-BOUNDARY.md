# qFoldIT UNIGINE Toolbelt IP Boundary

This repository is an intentionally public runtime adapter surface. Published source remains governed by its applicable open-source license and attribution terms.

## Public boundary

The public Toolbelt contains generic UNIGINE automation, UAG adapter behavior, industrial visualization and reusable runtime integration mechanisms intentionally published by qFoldIT.

## Private boundary

Confidential customer workflows, private mission policies, protected scientific references, credentials, signing material and undisclosed commercial algorithms belong in private qFoldIT repositories.

## Scientific boundary

Runtime interaction, physics and visualization do not establish scientific validity. Scientific evidence remains authoritative in the configured qFoldIT scientific validation service.

## Provenance

Production releases should preserve commit SHA, author, review reference, release identifier, artifact hashes and the corresponding qFoldIT IP evidence registry version.

## Third-party rights

UNIGINE and third-party assets retain their respective licenses and intellectual-property rights. This repository does not grant rights to third-party brands or assets.
