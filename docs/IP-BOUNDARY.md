# qFoldIT UNIGINE Toolbelt IP Boundary

This repository is an intentionally public runtime adapter surface. Its published source remains governed by the repository's applicable open-source license and attribution terms.

## Public boundary

The public Toolbelt contains generic UNIGINE 2 automation, UAG adapter behavior, MCP bridge tooling and reusable scientific-state visualization primitives that qFoldIT intentionally publishes.

## Private qFoldIT boundary

Confidential customer workflows, private mission policies, protected scientific references, credentials, signing material and undisclosed commercial algorithms belong in private qFoldIT repositories and infrastructure.

## Scientific boundary

Toolbelt capabilities describe runtime behavior. Scientific validity remains the responsibility of the qFoldIT scientific validation authority and evidence contract.

## Provenance

Production releases should preserve commit SHA, author, review reference, release identifier, artifact hashes and the corresponding qFoldIT IP evidence registry version.

## Third-party rights

UNIGINE and third-party packages, assets and services retain their respective licenses and intellectual-property rights. This repository does not grant rights to third-party content.
